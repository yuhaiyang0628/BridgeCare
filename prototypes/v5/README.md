# BridgeCare 双语聚焦版原型 · v5

v5 从 v4 独立复制，原始高保真原型、v2、v3、v4 均未改写。

- 打开 `index.html` 即可进入原型；需保留同目录的 CSS 和 JavaScript 文件。
- 作品集演示默认使用 English，初始病例为 Sarah Johnson · Booking overdue。
- 不调用在线翻译服务。电话、医院连接、患者通知和医生审阅均为模拟。
- 诊疗建议和自动临床解读不在原型范围内。

## 两种语言互不覆盖

### 转诊协调员工作台

- 桌面端在顶部语言按钮间切换 **English / 中文**；手机端在底部导航点击语言按钮，按钮会显示可切换到的语言。
- 切换只重新渲染当前页面文案。病例阶段、预约结果、通话结果、当前向导步骤和未提交表单值由独立状态保留。
- **Reset demo** 将病例重置为 Sarah 的 Booking overdue 场景，但保留工作台语言与患者预览语言选择。刷新页面则按作品集默认值重新载入英文演示。
- 向导中的医院、人名、转诊原因和首选语言仍是用户填写的原文；预约地点、日期和医院说明也不会随顾问端语言切换而改写。

### 患者预览

- 患者预览默认按病例的 **Preferred language** 显示。原型支持中文和英文；不支持的偏好值暂回退为英文。
- 预览页提供独立的 **Preview language** 控件。它只改变患者端预览，不修改病例语言偏好，也不改变顾问端语言。
- 患者端关键状态区分为：报告已收到、医生已审阅、随访已安排。预约日期、医院、地点和说明沿用病例中的原始记录。

### 中文文案

- 已统一使用“转诊协调员”“接诊医院”“电话预约引导”等说法，减少照着英文词序翻译的表达。
- 电话话术改成中文口语顺序；患者提示更直接，并明确区分“报告已收到”“医生已审阅”和“随访已安排”。
- 医院、人名、转诊原因和预约说明仍保留原文，不随界面语言改写。

## 中文演示路径

### Booking overdue 与工作台切换

1. 首次进入后打开 Sarah’s case，再进入 Review alert 和 Guided booking。
2. 在桌面顶部或手机底部导航切换为中文；当前页面和病例阶段应保留。
3. 可进入 Patient preview；患者端默认按 Sarah 的 English 首选语言显示。用 Preview language 单独切换到中文，再切回英文。
4. 点击 Reset demo，应回到预约超时病例，同时保留工作台与预览语言选择。

### 五步向导中途切换

1. 从 Dashboard 的 Demo scenarios 选择 **Start from referral**，在五步向导中填写或修改患者与转诊资料。
2. 在任意一步切换中英文，检查步骤、已填字段、模板选择和可选口译勾选仍在。
3. 完成五步并启动任务链；病例应使用向导数据。更改患者姓名后，Dashboard 的病例卡和看板标题应显示新姓名。
4. **Exit setup** 表示离开设置，不再称为保存草稿。

### 未接通、重试、接通并确认

1. 从 Booking overdue 打开 Guided booking，选择 **No answer**，记录原因和重试期限。
2. 回到病例后切换工作台语言；病例应仍为 Call retry needed，患者端仍说预约未确认。
3. 再次进入预约，选择 **Connected**，填写医院确认的日期、时间、地点与说明后确认。
4. 检查病例、任务链、活动记录和患者预览中的预约信息一致。只有接通结果可完成预约确认。

### 报告延迟、收到、审阅与随访

1. Dashboard → Demo scenarios → **Report delayed**，从 **Open report task** 或病例页的 **Open report workflow** 进入报告处理。
2. 在延迟和报告工作流状态切换中英文；报告期限与病例阶段不应改变。
3. 选择接收报告并指定医生。此时中文患者提示是“检查报告已收到”，下一步仍等待医生审阅。
4. 再确认医生已审阅，患者提示变为“医生已审阅检查报告”；之后才可安排随访。
5. 保存医生、日期和时间后，患者提示为“已为您安排医生随访”，病例、Activity 和患者预览使用同一安排。

## 实现与静态验收记录

- Activity 保存事件类型和参数；按当前工作台语言渲染，不对已存英文句子做字符串替换。医院、人名和用户填写的内容作为参数原样显示。
- 患者预览文案从独立语言选择渲染，工作台语言切换不会覆盖预览语言。
- 状态模型保留正常阶段限制：未接通不能确认预约；报告收到后必须经过医生审阅才能安排随访。
- JavaScript 语法检查通过；`test-model.js` 通过模型转换、失败通话与重试、接通门槛、报告审阅顺序、中英 Activity 与患者状态文案检查。
- 显式翻译调用中的英文 key 静态核对通过，均有中文映射；界面中用户填写的数据节点标记为原文保留。
- HTML 静态解析、本地资源引用和 ID 唯一性检查通过；CSS 括号平衡，并静态确认 1250px、900px、700px、400px 响应式断点。
