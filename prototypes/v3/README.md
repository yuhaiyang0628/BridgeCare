# BridgeCare 聚焦版原型 · v3

本目录是从 v2 复制后继续完善的独立工作稿。原始高保真文件与 v2 均未改写。

- 打开原型：index.html
- 产品界面：英文
- 演示说明：中文
- 数据：只存在当前页面会话；刷新或点 **Reset demo** 会回到空白工作台
- 电话、患者通知和医院连接：全部为模拟操作
- 不包含完整模板编辑器、医院 API、真实拨号或自动临床解读

## 中文演示路径

### 1. 从空白工作台接收 Sarah 的转诊

1. 点右侧 **Reset**（桌面侧栏为 **Reset demo**），确认工作台回到 0 个病例、0 个异常。
2. 点 **+ New referral**，经过五步向导。
3. 患者信息保留 **Sarah Johnson**；可改语言，观察审核页和病例字段是否同步。
4. 转诊上下文填写来源医院、接收医院、科室和转诊原因；可改原因，用来核对异常页是否仍使用实际录入内容。
5. 选择 **OB Referral · Interpreter-ready**，在 **Adjust optional steps** 保留或取消 interpreter。建议保留以演示可选任务。
6. 在 Review 页启动任务链。新病例应只在启动后出现在工作台。
7. 若保留 interpreter，先在病例页点 **Assign interpreter in mock**，再点 **Advance demo to booking deadline**。若取消了 interpreter，可直接推进。

### 2. 发现并处理预约超时

1. 推进演示时间后会回到 Dashboard；打开 Sarah 的异常。
2. 查看接收医院、科室、实际转诊原因和负责人。
3. 从异常页进入 **Guided hospital booking**；病例、Dashboard 和患者预览此时都应显示预约未确认。

### 3. 记录一次未接通，再重试并确认预约

1. 点 **Start simulated call**，选择 **No answer**。
2. 录入未接通原因和重试时间，点 **Record attempt and assign retry**。
3. 回到病例页后核对任务链的 booking 状态、Activity 中的重试负责人和期限；患者预览仍应显示 **Not confirmed yet**。
4. 从病例或异常页再次进入预约，重新开始模拟通话，选择 **Connected**。
5. 录入日期、时间、楼栋/签到位置和医院说明，再确认预约。
6. 核对病例预约条、Activity 和 Patient preview（包括手机卡片）显示相同预约信息。此时预约任务完成、异常计数归零。

### 4. 追踪报告、完成医生审阅并交接随访

1. 在病例页点 **Advance demo to after visit**，再打开报告工作流。
2. 先点 **Record report delay** 并填写跟进期限。回 Dashboard 检查异常卡和任务链是否同步。
3. 打开报告工作流，点 **Mark received and route for review**，指定医生。报告收到后异常解除，但任务链应显示临床审阅待处理。
4. 点 **Confirm clinician review** 后，才进入 **Arrange follow-up**。未确认审阅前，状态规则不允许安排随访。
5. 填写医生、日期和时间并安排。最后检查 Activity、病例页及患者预览中的下一步和随访预约一致。

### 返回与重置

- 异常、预约、报告、临床审阅和随访页面均有 **Back to case**。
- 患者预览有 **Back to case**；主导航可回 Dashboard。
- 任一页面都可点 **Reset**；重置后应无 Sarah 病例、无异常、无预约或旧 Activity。重新打开向导应回到默认值。

| 场景 / 项目 | 当前结果 | 验证依据 |
|---|---|---|
| 向导字段写入病例、模板与 optional interpreter 配置 | 状态规则通过；界面点击未验证 | 状态转换检查 + 静态追踪 draft 捕获、CREATE 和病例渲染路径 |

## v3 修正记录

- v2 异常页把转诊原因写死成 fetal cardiac echo；改了向导后异常页会讲另一件事。v3 改为读取 Sarah 的病例字段。
- v2 模型可以在未记录医院已接通时直接确认预约。v3 要求确认动作带有 connected 结果；未接通分支只建立重试任务。
- v2 患者预览没有呈现医院说明，下一步文案还固定写成护照与转诊信；若顾问录入不同要求，两端会不一致。v3 把地点和医院说明从同一预约记录展示在病例、Activity 与患者预览。
- v2 报告延迟后收到报告会丢弃原跟进期限。v3 收到报告时保留该期限，并继续要求医生审阅后才能随访。
- v2 的次级工作页面主要依赖侧栏切换；v3 在异常、预约、报告、审阅、随访和患者预览页加入明确的回病例入口，并按病例阶段拦截不可用路由。
- v2 dashboard 降成统计卡和病例列表，丢失原稿的看板结构；v3 恢复四阶段任务看板、异常队列、渐变强调和浮层侧栏，仍然只展示 Sarah 这条核心故事。
- v2 未引入原稿的 Outfit / DM Sans 字体声明。v3 恢复字体链接与系统回退字体，并加入手机导航、窄屏单列、键盘焦点和减少动效支持。
