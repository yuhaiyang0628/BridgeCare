# BridgeCare 聚焦版原型 · v2

这是基于交接资料重新整理的独立版本。打开 `index.html` 即可查看。原版文件保持原样；本原型只使用本地模拟数据，不会真实拨号、连接医院、发送患者通知或存储医疗记录。

## 叙事范围

以 Sarah Johnson 的一次跨院转诊串联转诊员的四项工作：

1. 接收转诊，选择任务链模板，调整可选步骤并启动。
2. 发现超时预约，查看背景，决定下一步。
3. 在没有医院接口的情况下引导式电话预约；失败则记录重试责任与期限，成功则更新任务链和患者端预览。
4. 检查后追踪报告，确认医生完成审阅，安排随访。

工作台上的其他患者卡片只提供工作量背景。这个版本不包含完整模板编辑器、真实医院接口、消息发送和自动临床解读。故事中的时间推进由明确标注的演示按钮触发。

## 建议演示路径

1. 点击 **New referral**，完成五步向导。可修改患者姓名、接收医院，或勾选翻译员任务，查看审核页和病例如何变化。
2. 从病例页点击 **Advance demo to booking deadline**；返回工作台，打开 Sarah 的异常。
3. 进入 **Guided hospital booking**。先选 **No answer** 并记录重试，再重新进入预约，选择 **Connected**，填写日期和时间并确认。
4. 打开 **Patient preview**，核对预约信息。从病例页推进到检查后。
5. 记录报告延迟，再标记报告收到；确认医生审阅后安排随访。最后核对患者端预览与活动记录。

点击 **Reset demo** 可回到初始状态。刷新页面也会重置，状态只保存在当前打开的页面中。

## 检查

在本目录运行 `node test-model.js`，可检查关键状态转换及禁止跳步的规则。由于当前环境的浏览器安全策略阻止打开这个本地页面，界面的视觉与逐次点击检查仍需在你的浏览器中完成，之后再用于作品集截图。

浏览器走查时重点核对：

- 创建前工作台没有 Sarah；启动任务链后才出现，且向导输入在病例页保持一致。
- 选择翻译员步骤后，必须先完成模拟分配才能推进到预约期限。
- “No answer”只生成重试任务，不能显示预约成功；确认预约后工作台异常消失，病例和患者预览显示相同的日期与时间。
- 报告延迟会产生待处理事项；收到报告后仍需确认医生审阅，才能安排随访。
- 刷新或重置后恢复初始场景；界面在桌面与手机宽度下均可阅读。
