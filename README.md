# BridgeCare

面向外籍患者跨院转诊服务的作品集项目。项目从服务满意度与业务瓶颈出发，聚焦转诊员在转诊、预约、就诊、报告与随访中的工作准确性、可靠性和效率。患者场景用于说明服务体验如何受到内部流程影响。

## 从哪里开始

- [最新交互原型 v6](prototypes/v6/index.html)：双语界面与演示病例；工作台、病例页、引导式预约页采用新的浅色视觉方向。
- [v6 演示路径与验收状态](prototypes/v6/README.md)：包含可演示流程、已检查内容及尚未完成的浏览器点击和视觉验收。
- [v6 视觉规范](prototypes/v6/VISUAL-SPEC.md)：颜色、字体、组件与关键页面结构。
- [原始作品集版式](portfolio/layout/index.html) 与 [Research 扩展稿](portfolio/research-expanded/index.html)：目前是分开的工作稿，尚未合并成最终作品集。
- [项目交接文档](docs/BridgeCare_项目交接文档.md)：记录较早阶段的进度和材料，部分叙事判断已更新，阅读时请结合下方说明。

本地下载或克隆后，直接打开相应目录中的 `index.html` 即可查看静态页面。原型使用演示数据，不连接医院系统，也不执行真实拨号、患者通知或临床操作。

## 当前状态

- v6 仍是视觉方向稿：其余流程页只应用了共享的浅色基础，尚未全部完成视觉重构。
- 状态模型与静态检查不能代替浏览器验收；实际点击、桌面及手机布局仍需人工检查。
- 作品集叙事正在调整：以公司的服务满意度问题为起点，说明为何转诊员的工作流程成为设计重点。早期文档和版式中以患者故事开篇的结构尚未统一修订。
- 研究人数、访谈内容和效果数字等工作稿表述需要依据原始证据核实后，才能作为最终作品集结论。

## 版本关系

各版本彼此独立，保留用于回看设计过程。建议从 v6 查看当前视觉方向，从 v5 查看视觉重构前较完整的双语流程。每版具体演示路径见对应 README。
